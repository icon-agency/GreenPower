# GreenPower favicon pack

Developer-ready favicon and web-app icon set based on the current GreenPower leaf-tick brandmark.

## Recommended files

- `favicon.svg` - preferred modern browser favicon
- `favicon.ico` - legacy browser fallback (16, 32 and 48 px embedded)
- `apple-touch-icon.png` - iOS home-screen icon, 180 x 180
- `android-chrome-192x192.png` and `android-chrome-512x512.png` - PWA icons
- `maskable-icon-512x512.png` - PWA maskable icon
- `site.webmanifest` - web app manifest
- `implementation.html` - copy-and-paste HTML head tags

## Source and colour

The leaf-tick path was extracted from the current GreenPower Brand Use and Claims Guidelines (January 2026, Version 2.0). The primary green is `#009F4D`.

The current GreenPower website states that logo use must follow the brand guidelines and may require Program Manager approval before publishing.

## Installation

Copy the files to the site's public web root, then add the tags from `implementation.html` to the document `<head>`. Adjust paths if the assets live in another folder.
